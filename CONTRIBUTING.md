# Вклад в развитие PulseProxy

Мы приветствуем предложения новых источников, оптимизацию парсеров и пулов SNI/CIDR.

## Как предложить новый источник
1. Добавление глобального источника: внесите изменения в `source/config/urls.json`.
2. Добавление источника под белые списки РФ: внесите изменения в `source/config/30_urls.json`.
3. Требования к источнику:
   - Должен отдавать ссылки на raw-списки (txt / base64).
   - Не должен требовать прохождения капчи или Cloudflare Turnstile.
   - Источник не должен быть дубликатом уже имеющихся в списке.

## Разработка и PR
1. Форкните репозиторий и создайте ветку с осмысленным названием (`feat/`, `fix/`).
2. Установите зависимости: `pip install -r source/requirements.txt`.
3. Проверьте код линтером (flake8 / ruff) перед созданием PR.
4. Убедитесь, что `main.py` завершает работу без исключений при локальном запуске (без `MY_TOKEN` коммиты не отправляются).
